## Project Overview

Welsh Roots is a cultural and educational Android application designed to introduce users to Wales through its history, folklore, museums and cultural heritage.

Originally developed as part of the SEN5001 Mobile and Web Technologies module at Cardiff Metropolitan University, the application provides an accessible platform for exploring Welsh heritage, with particular emphasis on museums, historical exhibitions, folklore and cultural events.

## Features

- **Museum Exploration** – Information, exhibitions and highlights from museums across Wales.
- **Virtual Museum Tours** – Embedded YouTube tours and Google Street View integration.
- **Welsh Heritage Library** – Educational articles covering Welsh history, folklore and urban legends.
- **Interactive Maps** – Google Maps integration displaying the locations of featured Welsh museums.
- **Bilingual Support** – English and Welsh language options.
- **Authentication** – User registration and login through Firebase Authentication.
- **Personalisation** – Light and dark themes with persistent user preferences.
- **User Reviews** – Functionality for submitting and viewing application reviews.
- **Accessibility** – Screen reader support and adjustable text sizes.
